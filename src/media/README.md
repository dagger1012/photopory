# Your photos & videos

Drop files into these folders and they appear on the site automatically. No code changes needed.

- `hero/` — first file is the big home page photo
- `home-work/` — "Recent frames" grid on the home page
- `services/<service-name>/` — gallery on that service page (first image is also the cover)

Supported: .jpg .jpeg .png .webp .avif (photos), .mp4 .webm (videos).
Files are shown in filename order — name them `01-…`, `02-…` to control order.
Empty folder = placeholder photos are shown.
